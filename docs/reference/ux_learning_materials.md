# Access UX learning materials

Locate or open the educational materials included in the package.

## Usage

``` r
ux_learning_materials(material = "all", open = FALSE)
```

## Arguments

- material:

  Material to access: 'all', 'workbook', or 'answer_key'.

- open:

  Logical. If TRUE, opens the selected material.

## Value

Invisibly returns the file paths of the selected materials.
