# Synthetic Banking Usability Dataset

A synthetic dataset representing usability testing sessions conducted
with participants interacting with a digital banking application.

## Format

A data frame with 150 rows and 9 variables:

- participant_id:

  Participant identifier.

- task_id:

  Task identifier.

- participant_experience:

  User experience level.

- task_name:

  Banking task performed.

- task_difficulty:

  Task difficulty category.

- success:

  Task completion indicator (0 or 1).

- time_seconds:

  Task completion time in seconds.

- errors:

  Number of errors during the task.

- satisfaction:

  User satisfaction score (1 to 7).

## Source

Generated with the uxlearn package.

## Details

The dataset contains observations from 30 participants completing five
common banking tasks.

This dataset contains synthetic educational data. It does not represent
real users or empirical findings. It is intended for teaching usability
evaluation, UX metrics, data analysis and evidence-based design.
